# 媒体投射工具 · Windows

适用于 Windows 11 x64，配合 Android 13 或更新版本。先在系统蓝牙设置中配对电脑与手机。在手机端授予附近的设备与通知访问权限，然后选择这台电脑。在 Windows 主窗点击「切换手机」，选择已配对的手机。

将解压后的文件夹放在固定位置，双击「安装到开始菜单.cmd」，再从开始菜单搜索「媒体投射工具」。也可直接打开 `MediaProjection.exe`。安装只创建当前账户的开始菜单快捷方式。

| 快捷键 | 操作 |
| --- | --- |
| Caps + ← / → | 上一曲 / 下一曲 |
| Caps + ↑ / ↓ | 音量加一格 / 减一格 |
| Caps + 空格 | 播放 / 暂停 |

音量键按下立即调一格。按住约 350 毫秒后，每 150 毫秒再调一格，松开 Caps 或方向键即停止连发。切歌和播放暂停在方向键或空格松开时执行，按住超过 350 毫秒再松手可取消。

关闭或最小化主窗口会收至托盘。双击托盘图标恢复主窗口，右键菜单里的「退出」会停止 Windows 遥控。可在主窗口或托盘开启一行曲目小窗和登录时启动，两项默认关闭。连接丢失后自动重连，也可以点「重连」。

开启曲目小窗后默认贴在主屏任务栏「显示隐藏的图标」按钮左侧的空位。小窗左边显示媒体音量数值，中间的进度条上方左侧显示已播时间，右侧显示总时长。鼠标悬浮在进度区或拖动时，滑块放大。右边滚动超长曲名。单击音量或曲名可打开主界面。想从任务栏拖到桌面时，先在托盘选「小窗位置 → 移动小窗」。任务栏暂时无法停靠时，小窗临时显示在桌面右下角，能停靠后会自动贴回。

在任务栏中，小窗默认使用透明底和浅青绿色文字，曲名加粗，显示区占任务栏一半高度并垂直居中。可在托盘「任务栏小窗底色」切换透明、淡底和深底。底色选项只改变背景透明度，选择会保存。

打开任务栏的时钟、通知或托盘面板时，小窗保留已确认的位置。面板关闭后会重新核对任务栏空位。只有布局变化持续存在时才会调整停靠位置。

小窗使用 Windows 的普通置顶。停靠时，任务栏如果盖住小窗，程序会把小窗放回任务栏正上方。截图等覆盖界面保留自己的层级。

超长曲名按所在屏幕的刷新率滚动，最高 120 Hz。短曲名静止显示。

配合手机端 0.1.3 或更新版本，手机音量或播放状态变化时会通过蓝牙直接更新小窗。连接时读取曲名，曲名有变化时再读取一次。空闲时没有媒体状态轮询。

配合手机端 0.1.5，主窗口和小窗都显示播放时间和总时长。播放器支持跳转时，点击或拖动进度条并松手即可跳到指定时间。主窗口进度条聚焦后可用方向键每次跳五秒。播放进度在本机推进，播放器状态变化通过蓝牙通知，跳转后按需补读一次。

命令入口在 `Control-MediaProjection.ps1`。应用运行时，`status`、`version` 可从后台查看状态，`hide` 收至托盘，`reconnect` 重连，`exit` 优雅停止。`MediaProjection.exe --tray` 可后台启动。另有 `previous`、`next`、`play-pause`、`volume-up`、`volume-down` 用于媒体控制，并返回是否已入队。

`progress refresh` 单次请求读取进度，结果可从 `status` 查看。`seek -PositionMs 60000` 可将支持跳转的曲目移至 1:00。
