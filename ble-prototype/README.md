# 媒体投射工具 · Android

Android 13 或更新版本。安装后允许「附近的设备」，开启「通知访问」，再从已配对设备中选择电脑。可从应用页面停用蓝牙遥控。

应用由 Android 绑定通知监听服务，通过系统媒体会话读取播放状态和发送媒体控制。BLE 服务仅接受手机端选定的已配对设备。连接空闲时使用事件通知，进度由电脑根据锚点推进。进度条依赖播放器提供时长和跳转能力。

## 构建

在 Windows 安装 Android SDK Platform 36、Build-Tools 36.0.0 和 JDK 17 或更新版本。设置 `ANDROID_HOME` 和 `JAVA_HOME`，或通过 `-AndroidSdk`、`-JavaHome` 显式提供路径。

```powershell
.\Build-Android.ps1
```

输出在 `out/`。脚本首次运行会创建本地测试签名密钥。自行构建的 APK 使用自己的签名，覆盖安装需要和原包使用同一个签名。

## 蓝牙状态

基础状态通知包含状态序号、曲目序号、播放标志和音量。曲目文字按需分页读取。进度特征通过 17 字节锚点发送曲目序号、位置、总时长、速度和可跳转标志。跳转命令带曲目序号和目标毫秒数，手机端在验证曲目、范围和跳转能力后执行。
